# АКОС: Zsh, tmux и Vim


## 1. Установка Zsh и плагинов

Zsh — оболочка, которая понимает команды. Oh My Zsh — набор настроек и плагинов для неё.

### Установить программы

```bash
sudo apt-get update && sudo apt-get install -y zsh curl git tmux vim
```

Здесь сразу устанавливаются Zsh, tmux и Vim. `curl` и `git` нужны для установки Oh My Zsh и плагинов.

### Установить Oh My Zsh

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

Если установщик предложит сделать Zsh оболочкой по умолчанию, можно согласиться. Если после установки вы остались в Bash, перейти в Zsh:

```bash
zsh
```

### Подключить подсказки и подсветку

Далее выполнять **в Zsh с загруженным Oh My Zsh**, без `sudo`:

```zsh
git clone https://github.com/zsh-users/zsh-autosuggestions ~/.oh-my-zsh/custom/plugins/zsh-autosuggestions
git clone https://github.com/zsh-users/zsh-syntax-highlighting ~/.oh-my-zsh/custom/plugins/zsh-syntax-highlighting
```

Включить плагины:

```zsh
omz plugin enable git zsh-autosuggestions zsh-syntax-highlighting
```

Команда обновляет список плагинов в `.zshrc` и перезагружает интерактивную Zsh-сессию. Если получаете `omz: command not found`, сначала проверьте, что запущен Zsh и установлен Oh My Zsh. [Команды Oh My Zsh](https://github.com/ohmyzsh/ohmyzsh/blob/master/lib/cli.zsh)

- **zsh-autosuggestions** — серые подсказки по истории команд.
- **zsh-syntax-highlighting** — подсветка вводимой команды; она не гарантирует, что команда безопасна или правильна.
- **git** — готовые сокращения и дополнения для Git; входит в Oh My Zsh.

### Полезные клавиши в оболочке

| Клавиша | Действие |
| --- | --- |
| Tab | Дополнить команду или путь |
| ↑ | Вернуть предыдущую команду |
| → в конце строки | Принять серую подсказку autosuggestions |
 |
| Ctrl+C | Отменить текущий ввод или запросить прерывание запущенной программы |

## 2. Основные команды tmux

Tmux позволяет работать с несколькими окнами и панелями терминала, отсоединяться от сессии и возвращаться к ней.

### Команды из обычного терминала

| Команда | Действие |
| --- | --- |
| `tmux new -s demo` | Создать сессию с именем `demo` |
| `tmux ls` | Показать сессии |
| `tmux attach -t demo` | Вернуться в существующую сессию `demo` |

### Клавиши внутри tmux

**Сначала нажать Ctrl+B, отпустить обе клавиши, затем нажать указанную клавишу.** Это стандартные сочетания; при личных настройках они могут отличаться.

| После Ctrl+B | Действие |
| --- | --- |
| `d` | Отсоединиться, не завершая сессию |
| `c` | Создать новое окно |
| `w` | Показать список окон |
| `n` / `p` | Следующее / предыдущее окно |
| `%` | Разделить на левую и правую панели |
| `"` | Разделить на верхнюю и нижнюю панели |
| `o` | Переключиться на следующую панель |
| `z` | Развернуть панель; повторить, чтобы вернуть размер |

`exit` завершает оболочку в текущей панели

## 3. Основные команды Vim

Vim — текстовый редактор внутри терминала.

```bash
vim notes.txt
```

### Ввод и перемещение

| Клавиша | Действие |
| --- | --- |
| `i` | Перейти в режим ввода текста |
| Esc | Вернуться в Normal — режим команд |
| Стрелки | Перемещать курсор |

### Команды после Esc

**После команд с `:` или `/` нажимать Enter. Для остальных строк таблицы Enter не нужен.**

| Команда | Действие |
| --- | --- |
| `:w` | Сохранить |
| `:q` | Выйти, если нет несохранённых изменений |
| `:wq` | Сохранить и выйти |
| `:q!` | Выйти, отбросив несохранённые изменения |
| `u` | Отменить последнее изменение |
| Ctrl+R | Вернуть отменённое |
| `x` | Удалить символ под курсором |
| `dd` | Удалить строку |
| `yy` | Скопировать строку |
| `p` | Вставить скопированное или удалённое в Vim |
| `gg` | Перейти в начало файла |
| `G` | Перейти в конец файла |
| `/слово` | Найти слово |
| `n` / `N` | Следующее / предыдущее совпадение |
